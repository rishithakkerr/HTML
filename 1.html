What is the difference between a normal div and a grid container?
A normal div stacks elements veritcally by default while a grid container allows us to arrange elements using rows and columns.
Why does the layout look the same even after applying Grid?
Because no number of rows and columns have been defined, so the grid arranges the elements in one column, so they appear normal.
Are grid items created automatically?
Yes, every item directly under the grid container will automatically become a grid itemand be arranged
Can Grid work without rows or columns?
Technically grid will still work without specifying the columns and rows but without the defined rows and columns there will be no visible changes.
What do you think Grid needs to show visible changes?
Grid needs defined properties like rows and columns or the gap between them to visbily look like a grid.
